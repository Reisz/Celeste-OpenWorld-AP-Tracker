# Celeste-OpenWorld-AP-Tracker

[PopTracker](https://poptracker.github.io/) pack for [Celeste OpenWorld AP](https://archipelago.gg/games/Celeste%20(Open%20World)/info/en).

## Working on the pack

All workflow processes are encoded in the [justfile](`justfile`).
Use `just --list` to see available recipes.

### Required software

- [just](https://just.systems/)
- [uv](https://docs.astral.sh/uv/)
- [jq](https://jqlang.org/)
- [curl](https://curl.se/)
- [fd](https://github.com/sharkdp/fd)
- `zip` / `unzip`
- `cmp`
- `xargs`
